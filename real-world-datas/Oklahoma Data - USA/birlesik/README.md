# Prepared Oklahoma fiscal-year inputs

This local directory contains `oklahoma_FY2009.csv` through `oklahoma_FY2027.csv`, with one header per file. These already prepared files are the declared Oklahoma profiling inputs. They are not the original 170-download collection described in the upstream note.

The twelve fields are `fiscal_year`, `txn_date`, `date_source`, `post_date`, `merchant`, `mcc_desc`, `item_desc`, `amount`, `agency`, `package_title`, `resource_id`, and `source_file`. The `date_source` field distinguishes transaction dates from reporting-period-derived dates; upstream source identity fields are retained as provenance.

Only this README is eligible for publication from this directory. The CSV files remain local. The combined `../birlesik_tam.csv` also remains local and is not selected as an additional profiling input. See the [source README](../README.md) for scope and public report links.
