# Real-world source directories

These directories document the original local dataset layout. Only `README.md` files from this tree are eligible for Git tracking. Original datasets, XLSX-to-CSV conversions, and merged transaction CSVs remain local and are not distributed.

The scientific study uses the eleven sources configured in [data_profile/config/sources](../data_profile/config/sources/). The Indonesia dataset and earlier concatenations are outside its input selection. See the [data card](../outputs/DATA_CARD.md) for scope and the [manifest](../outputs/manifest.csv) for recorded input metadata and hashes.

Source-folder READMEs retain supplied source links where available. Obtain data from its publisher under the applicable terms and place authorized local copies at the configured paths to reproduce the analysis.
