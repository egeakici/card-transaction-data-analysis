# Data Availability Statement

Status: 2026-11-04. The following paragraph describes the current repository and can be used as the study's present availability statement.

> Analysis code and scientific reports are available at [egeakici/card-transaction-data-analysis](https://github.com/egeakici/card-transaction-data-analysis). The study analyses locally supplied records from ten public bodies and one academic bank-transaction dataset (eleven sources in total). Original transaction data, consolidated CSVs, transaction-level intermediates and internal annotation samples are not distributed through this repository. Source links, published licence evidence and unresolved permission issues are documented in [licenses.yaml](licenses.yaml), [DATA_LICENSING.md](DATA_LICENSING.md) and [ATTRIBUTION.md](ATTRIBUTION.md). Some existing derived tables include source wording or screened examples and are not covered by a blanket data licence. The project's original software is available under the [MIT licence](LICENSE), separately from source data and third-party material. No annotated v1.0 dataset or Zenodo release is currently documented.

The Mendeley DOI in the credits identifies MoneyData, an external input source. It is not a DOI for this study's combined or annotated data. Access to source records must be obtained from their publishers under the applicable terms. No promise of universal download availability, historical snapshot completeness or permission by request is made.

A future record-identifiers/annotations/retrieval-code release for restricted sources has not been implemented or cleared. Do not replace this statement with the proposed Zenodo/CC BY 4.0 wording until a real, rights-reviewed release exists.
